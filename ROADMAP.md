# Roadmap

## `size`

- Add support for parsing YAML configs.
- Add support for MiB, KiB, etc.
- Add a support bit.

## `mime`

- Expand the registers of existing providers and their typical subtypes.
- Implement the IsArchive() method.
- Implement a method for getting optional parameters for a MIME string.

## `files`

- Add the File and MediaFile interfaces.
- Expand the extension type (files.Extension).
- Expand the number of supported file types.
- leave the check of Windows reserved names only for Windows assemblies.

## `magic`

- A subpackage for identifying files by their magic signatures.
