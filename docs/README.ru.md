# files 
[![go tests](https://github.com/vortex142/files/actions/workflows/go-tests.yml/badge.svg)](https://github.com/vortex142/files/actions/workflows/go-tests.yml) [![codecov](https://codecov.io/github/vortex142/files/graph/badge.svg?token=29V742D8P2)](https://codecov.io/github/vortex142/files) [![Go Report Card](https://goreportcard.com/badge/github.com/vortex142/files)](https://goreportcard.com/report/github.com/vortex142/files) [![Doc](https://img.shields.io/badge/godoc-blue.svg)](https://pkg.go.dev/github.com/vortex142/files) ![Go](https://img.shields.io/badge/go-1.24-blue.svg)

**Files** — библиотека для работы с метаданными файлов без прямого взаимодействия с файловой системой (I/O-agnostic). Пакет заменяет небезопасные манипуляции с «сырыми» строками на строго типизированную доменную модель, обеспечивая встроенную санацию имен, унифицированное представление файловых типов и инструментов для работы с размерами данных.

Сабпакет `mime` расширяет возможности основного пакета, предоставляя инструментарий для работы с MIME-строками в рамках общей доменной концепции. Интеграция с типами библиотеки позволяет классифицировать контент напрямую, заменяя избыточные линейные проверки (вроде `IsAudio` или `IsVideo`) на эффективное сопоставление с категориями контента.

## Name

Пакет `files` предоставляет тип `Name` — умную обертку над string, которая берет на себя всю «грязную» работу по валидации и нормализации имен файлов, обеспечивая кроссплатформенную совместимость и безопасность.

### Санация имени

Метод `Prepare` вырезает недопустимые символы и нормализует строку. Если в результате очистки получается зарезервированное системой имя (например, `con.exe` в Windows), метод безопасно трансформирует его в `_con.exe`.

```go
name := Name("../../etc/password")
name.Prepare() // name -> "....etcpassword"
```

### Валидация имени

Метод `Validate` проверяет длину имени, наличие запрещенных символов и попытки Path Traversal `(../../)`. Отдельно контролирует зарезервированные имена Windows (CON, PRN, AUX и др.), что критично для серверов, работающих с разными ОС.

```go
name := Name("../../etc/password")
if err := name.Validate(); err != nil {
  // handling invalid file name
}
```

### Удаление расширения

Метод `CutExtension` извлекает и удаляет расширение, модифицируя текущее имя. Метод корректно обрабатывает файлы с несколькими точками, отделяя только финальную часть после последней точки.
```go
n := Name("video.test.mp4")
ext := n.CutExtension() // n -> "video.test", ext = "mp4"
```

## Type

`files.Type` — это enum (uint8), классифицирующее файлы по их функциональному назначению.

### Поддерживаемые категории:

- **Audio** — звуковые файлы
- **Video** — видеопотоки и контейнеры.
- **Image** — растровые и векторные изображения.
- **Document** — текстовые документы, таблицы, презентации.
- **Archive** — сжатые пакеты.
- **Font** — шрифтовые файлы.
- **Unknown** — неопознанные данные.

## Сабпакет `size`
Пакет `size` предназначен для работы с объемами данных в байтовом представлении. Вместо использования обычных чисел, он вводит тип `Size` (обертка над float64), который берет на себя всю рутину по конвертации, парсингу и форматированию.

### Конструктор `New`

Конструктор `New` Позволяет создавать `Size`, указывая значение и единицу измерения (`Unit` — тип uint8).
```go
s := New(1, Kb) // 1024
s = New(1, Mb) // 1048576
```

### Парсинг строк

Конструктор `FromString` извлекает значение из строк вида "10 MB", "1.5 GB", "GB 10" и т.д.
> Максимальный размер строки ограничен 1024 байтами. Это предотвращает попытки эксплуатации парсера слишком длинными входными данными.

```go
FromString("10 MB") // s -> 10485760
FromString("1   kb") // s -> 1024
```

### Интеграция с JSON
`Size` реализует интерфейс `json.Unmarshaler`. Это позволяет парсить конфиги, где размер может быть указан как строкой ("10 GB"), так и числом (количество байт).

```go
type Config struct {
  MaxUploadSize Size `json:"max_upload_size"`
}
```

### Конвертация

Метод `To` возвращает значение размера в указанных единицах измерения.
```go
s := New(1, Mb)
val := s.To(Kb) // val = 1024
```

### Поддерживаемые единицы измерения (`Unit`)

| Константа | Значение (байт) | Описание |
| :--- | :--- | :--- |
| `B` | 1 | Байт |
| `Kb` | 1024 | Килобайт (2¹⁰) |
| `Mb` | 1,048,576 | Мегабайт (2²⁰) |
| `Gb` | 1,073,741,824 | Гигабайт (2³⁰) |
| `Tb` | 1,099,511,627,776 | Терабайт (2⁴⁰) |
| `Pb` | 1,125,899,906,842,624 | Петабайт (2⁵⁰) |
| `Eb` | 1,152,921,504,606,846,976 | Эксабайт (2⁶⁰) |

## Mime

Пакет `mime` является расширением основного пакета `files`. Он предназначен для типизированной работы с MIME-строками. Тип `Mime` представляет собой обертку над string.

### Валидация

Метод `Validate` проверяет соответствие строки стандартам RFC, а также контролирует наличие обязательных частей (тип и подтип).
> Максимальный размер MIME-строки ограничен 1024 байтами. Это предотвращает попытки эксплуатации парсера слишком длинными входными данными.

```go
m := Mime("audio/mpeg")
if err := m.Validate(); err != nil {
  // handling invalid mime
}
```

### Парсинг

Методы `Type`, `Subtype` и `Parts` позволяют эффективно разделять MIME-строку на составляющие.

```go
m := Mime("text/plain;charset=utf-8")
t, err := m.Type() // return "text"
s, err := m.Subtype() // return "plain"

// Get all parts in one call
t, s, err = m.Parts()
```

### Проверка категорий

Тип `Mime` предоставляет быстрые методы для определения категории контента:

- IsAudio()
- IsVideo()
- IsImage()
- IsText()
- IsApplication()
- IsFont()
- IsModel()

```go
m := Mime("audio/mpeg")
if m.IsAudio() {
  // logic processing audio file
}
```

### Интеграция с `files.Type`

Метод `FileType` позволяет конвертировать MIME-строку в основной перечислимый тип библиотеки.

```go
m := Mime("audio/mpeg")
ft := m.FileType() // return files.Audio
```

### Subtype

Пакет предоставляет тип `Subtype` — обертку над `string`, которая служит для идентификации и классификации форматов медиа-контента на основе их MIME-подтипов.

### Нормализация имени

Позволяет извлечь «эталонное» расширение или короткое имя формата из различных вариаций MIME-сабтипов. Это полезно для унификации имен файлов, приходящих из разных источников.

```go
wavSub := Subtype("vnd.wave")
mpegSub := Subtype("mpeg3")

n1, err := wavSub.Name() // n1 = "wav"
n2, err := mpegSub.Name() // n2 = "mpeg"
```

### Проверка семейства форматов

Тип `Subtype` предоставляет быстрые семантические методы для определения принадлежности контента к конкретному семейству, избавляя от ручного сравнения строк.

```go
s := Subtype("vnd.wave")
if s.IsWav() {
  // logic processing wav format
}
```

**Доступные методы проверки**:

- IsWav()
- IsMpeg()
- (список будет пополняться)

### Расширение поддержки

Регистры существующих вендоров и их специфических сабтипов ограничены. Пакет открыт для расширения: если вы столкнулись с редким или новым сабтипом, мы будем рады вашим Pull Request с добавлением новых сопоставлений в глобальный реестр (`mime/subtype.go`).

## Errors

### пакет `files`

- `ErrReservedName` — возвращается в случае совпадения с зарезервированными именами Windows (например, "CON", "NUL" и т.д.).
- `ErrEmptyName` — возвращается в случае пустой строки имени.
- `ErrEmptyPreparedName` — возвращается в случае, если после очистки имени ничего осталось.
- `ErrInvalidType` — возвращается в случае неизвестного типа файла.

### пакет `size`

- `ErrNegativeSize` — возвращается в случае отрицательного значения размера файла.
- `ErrInvalidUnit` — возвращается в случае недопустимого единицы измерения.
- `ErrEmptyParseStr` — возвращается в случае пустой строки для парсинга.
- `ErrTooLongParseStr` — возвращается в случае превышения максимального размера строки для парсинга (1024 байт).
- `ErrInvalidParseStr` — возвращается в случае отсутствия значения или единицы измерения в строке для парсинга.

### пакет `mime`

- `ErrEmptyMime` — возвращается в случае работы с пустой MIME-строкой.
- `ErrInvalidMime` — возвращается в случае некорректной MIME-строки (не содержит тип/подтип).
- `ErrTooLong` — возвращается в случае превышения максимального размера MIME-строки (1024 байт).
- `ErrEmptyType` — возвращается в случае пустого типа MIME.
- `ErrEmptySubtype` — возвращается в случае пустого подтипа MIME.
